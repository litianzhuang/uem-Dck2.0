管理员权限

正在核实

只有已获系统授权的管理员才能使用。

本页面管理本平台成员账户和受控共享项目目录；不授予成员管理员权限，不接触 Docker Socket，不删除个人科研数据。

创建成员账户

创建后密码仍锁定，管理员须单独设置安全登录凭据。系统会尝试配置 Rootless Docker 和 linger；运行与资源限制仍需验收。

账户停用原则

停用会尝试停止该成员的运行中容器和 Rootless Docker 服务并禁用 linger。未保存的训练进度可能丢失，操作前必须确认 checkpoint，并进行二次确认。

系统逐项报告账户锁定、会话、容器、服务、linger 和旧 Socket 状态；登录拒绝和其他授权路径尚需真实环境验收，结果为 PARTIAL 时必须人工核查。HOME、镜像、数据卷及 SSH 公钥保留。

平台管理的成员

—

状态来自本地账户库与 /etc/shadow 的非机密字段；口令仍锁定，需管理员单独登记凭据。平台管理员角色由 Cockpit/polkit 授权，网页不授予；可分配的角色为真实 Linux 项目组协作者。

创建共享项目目录

管理员须事先配置安全的项目目录入口，并创建并核对对应 Linux 组 uem-project-项目名的全部成员，包括以该组为主组的账户。组内成员对项目根目录有读写权限；本功能不会修改组成员。

目录创建不等于已配置容器共享、成员授权撤销或备份；新文件能否被组内其他成员修改还取决于文件权限和 umask。

查询项目组关系

操作项目组会影响该组可访问的所有位置，须先核查组用途和成员。授权允许成员按文件权限读写或删除共享数据。移除组成员不保证立即撤权：旧会话、进程、其他组或 ACL 仍可能保留访问。不会自动停止训练或删除数据。
