    数据口径与限制

    主机整体状态，仅供协商参考；不会阻止任务启动或保证资源充足。

    交换空间（swap）使用的是磁盘空间，速度通常慢于内存；此处是整机状态，不代表容器 swap 已被限制。

    各用户进程内存是可见进程的 RSS 合计，可能重复计算共享内存；权限和进程变化也可能导致遗漏，不等于精确实际占用。

    各用户 CPU 为最近一次短时采样、占整机所有 CPU 核心总算力的估算比例（约每两分钟刷新）；不可见进程和快速任务可能遗漏。

    GPU 使用者为根据系统进程信息推测，仅供协商；运行时长是进程时长，不是任务剩余时间。不提供预计结束时间。

      共享出口说明

      整台服务器共用一个校园网出口，同一时间只有一个认证会话。任一成员连接成功后所有成员立即可用，其他人不能再重复登录；断开会影响全体成员的下载和镜像拉取。

      创建科研环境

      自主选择镜像或模板

      环境与镜像

      2–40 个小写字母、数字或连字符；创建新版本时使用新名称。 模板由管理员固定镜像摘要和环境版本。 使用可信来源；不支持在地址中填写账号密码。可选请求所有 GPU；资源共享且兼容性待验证。 仅用于自选镜像；超过上限时容器内程序可能被终止。该设置不是整机内存预留。

      存储与创建

      选择已有工作空间可保留代码和模型文件；先停止使用该空间的旧容器。
